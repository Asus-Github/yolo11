《面向路侧实时感知的尺度先验小目标检测方法》
资深审稿意见、实质性修改说明与投稿建议

一、总体评价

原稿围绕 DAIR-V2X-I 路侧图像中的小目标检测问题，在 YOLO11n 基础上组合 DyHead、Wise-IoU v3、P2 高分辨率预测分支和 CoordAttention，实验数据较完整，应用场景明确。原稿最大的优点是：数据集中极小目标占比高，改进后 Recall 和 mAP@0.5:0.95 提升明显，尤其 Pedestrian 与 Trafficcone 的类别级增益具有场景合理性。

但原稿以“模块叠加”组织创新点，缺少从数据分布到结构选择的严密推导；不同训练口径的论文结果被并列展示，容易造成不公平比较；对 CoordAttention 和“实时性”的表述超过了消融和硬件证据可以支持的范围；此外，随机性控制、外部泛化和端侧部署验证不足。按原稿状态，审稿建议为“大修后重审”。

本次已经完成实质性重写，而非仅做语言润色。中文版被重构为“通用北核送审稿”；英文版根据 Springer 期刊 Signal, Image and Video Processing 的双栏 LaTeX 模板重写并控制在 9 页。所有数值均来自原稿实验记录，没有虚构新实验、置信区间或硬件结果。

二、原稿的主要问题及对应修改

1. 创新主线不清晰

原问题：
原稿将 DyHead、Wise-IoU v3、P2 与 CoordAttention 并列为同等创新，容易被审稿人评价为“现有模块简单堆叠”。没有回答为什么路侧场景需要这些改进，以及哪个组件真正决定性能。

本次修改：
将核心论证改为“数据尺度审计→预测分辨率选择→高分辨率证据保留”。在 640×640 输入下，79.65%的标注框面积小于32²像素，87.55%的目标短边小于32像素。由此推导 P3 特征图对极小目标只有约2～4个单元的短边覆盖，而 P2 可近似翻倍。论文据此将 P2 明确为主创新，DyHead 与 Wise-IoU v3 作为有效增强，CoordAttention 作为互补细化。

2. 消融结论与措辞不一致

原问题：
完整模型相较 DW-P2 仅将 mAP@0.5 从88.1%提高到88.4%，Recall 和 mAP@0.5:0.95 不变，但原稿对 CoordAttention 的贡献描述过强。

本次修改：
改为基于证据的分级结论：P2 是 Recall 与 mAP@0.5:0.95 提升的主要来源；DyHead+WIoU 构成有效强基线；CoordAttention 主要对 Precision 和 mAP@0.5 提供小幅辅助增益。正文同时提醒，0.3个百分点的单次运行差异不能被过度解释。

3. 跨论文比较不公平

原问题：
原稿将 YOLO-FLC 等已发表结果与本文结果并列，但类别数、batch、训练轮次和数据划分不同，不能据此直接声称优越。

本次修改：
把模型比较分为两类：
（1）YOLOv5n、YOLOv8n、YOLOv10n、YOLO11n：仅在同一划分、同一输入和同一训练口径下比较；
（2）YOLO-FLC 等已发表结果：仅作为性能范围和研究背景，不用于直接排名。
英文稿和中文稿均显式列出协议差异，避免误导性结论。

4. “实时性”表述过度

原问题：
100.5 FPS 来自 RTX 4090，无法直接代表路侧嵌入式设备，也没有包含解码、预处理、跟踪、通信和后处理。

本次修改：
加入单帧预算分析。模型延迟9.95 ms；对于25、30和60帧/s，扣除网络推理后分别剩余30.05、23.38和6.72 ms；对于100帧/s，仅剩0.05 ms，几乎没有系统余量。论文改为“GPU 上具有实时潜力”，不再声称已经完成端侧实时部署。GFLOPs、参数量和延迟增幅分别明确为2.25倍、1.73倍和约1.52倍。

5. 评价指标偏宏观，类别机制解释不足

原问题：
原稿整体指标充分，但没有把类别级增益与路侧尺度特征建立清晰联系。

本次修改：
新增类别级解释。Pedestrian 与 Trafficcone 的 mAP@0.5:0.95 分别提高8.5和8.0个百分点，Cyclist 与 Motorcyclist 分别提高4.0和3.1个百分点，这与 P2 保留细粒度空间信息的机制相符。同时指出 Truck 的 AP50 下降2.1个百分点、严格区间 AP 提高1.8个百分点，提示粗阈值检出与严格定位之间仍有权衡，需进一步用混淆矩阵和分桶结果诊断。

6. 统计可靠性未交代

原问题：
现有实验记录没有多随机种子重复、均值±标准差或置信区间。对小幅差异作确定性结论会被审稿人质疑。

本次修改：
没有虚构统计结果。在实验设置和局限性中明确说明所有小数级差异来自单次运行，并将“固定划分索引和随机种子、至少重复3次、报告均值±标准差”列为正式投稿前优先补充项。

7. 泛化和部署边界不清

原问题：
仅在 DAIR-V2X-I 上验证，且硬件为桌面级 GPU，不能支持跨城市、跨天气或嵌入式部署结论。

本次修改：
新增“有效性威胁与局限”小节，分别说明单数据集域偏移、多随机种子缺失、端到端时延缺失、尺寸/遮挡/天气分桶不足。后续方向具体化为跨城市外部验证、Jetson Orin/昇腾实测、减少 P2 通道、深度可分离卷积、剪枝、蒸馏和 TensorRT INT8 量化。

8. 论文结构和语言不够学术化

原问题：
原稿存在背景铺陈偏长、创新点和实验解释重复、公式变量定义分散、结论重复摘要等问题。

本次修改：
中文版重构为：引言—相关工作—数据尺度审计与设计准则—方法—实验设计—结果与分析—讨论—结论；英文版采用同一证据链，但按目标 SCI 期刊篇幅压缩。标题、摘要、贡献、图表标题、变量说明、讨论和结论全部重写。新增或重绘尺度分布、总体架构、整体指标、类别增益、精度—时延图；表格统一单位和比较口径。

9. 参考文献需要更新和规范

原问题：
部分引用页码不完整，较新的实时检测和小目标研究不足。

本次修改：
补充 YOLOv10、RT-DETR、2025年路侧检测、多尺度金字塔及跨层小目标研究；英文稿使用 BibTeX 和 Springer 数字编号样式；中文稿按国内期刊常用顺序编码体例统一。提交具体中文期刊前，仍需用该刊官方格式逐条核对中文标点、电子文献访问日期和作者数量。

三、对中文版“北核稿”的评价

修改后稿件的优点：
1. 研究问题、数据特征和结构改进之间形成了可验证的因果链；
2. 主要结论与消融结果一致，不再把所有模块包装成同等创新；
3. 同口径模型比较、类别级结果、复杂度和时延预算较完整；
4. 主动披露单数据集、单次运行和端侧验证不足，学术表述更稳健；
5. 图表经过统一重绘，数值和单位一致。

仍可能被北核审稿人追问的问题：
1. 方法仍由公开组件组成，理论新颖度有限，稿件更适合“工程应用/智能交通/计算机视觉应用”方向，而非强调基础算法原创性的栏目；
2. 最好补做3～5个随机种子重复实验，至少对 Baseline、DW-P2、DWCA-P2 报告均值±标准差；
3. 最好增加一组外部数据或跨场景测试；
4. 最好增加按小/中/大目标、遮挡程度或昼夜条件的分桶 AP；
5. 正式投稿必须补齐基金项目、通信作者电子邮箱、作者简介、ORCID（若期刊要求）、数据划分索引和代码可得性说明。

审稿立场：
修改后已经达到“可送审”的文本和版式质量，但任何期刊录用都取决于选刊匹配、补充实验、重复率、审稿意见和编辑判断，不能保证一定录用。若不补多随机种子与外部验证，建议选择偏工程应用、接受系统性组合改进的北核栏目。

四、SCI 期刊推荐

推荐期刊：
Signal, Image and Video Processing（Springer Nature）

推荐理由：
1. 研究范围直接覆盖 signal/image/video processing、目标检测和实时视觉方法，主题匹配；
2. Springer 官方期刊页标注为 SCIE，2025 Journal Impact Factor 为2.7；
3. 官方页面给出的 median submission to first decision 为4天，编辑处理速度较快；
4. 该刊为 Hybrid。选择传统订阅发表路线通常无需支付 APC；开放获取 APC 为可选项，并非必须，因此符合“版面费低”的目标；
5. 官方投稿指南要求使用 Springer Nature LaTeX 模板，推荐双栏 iicol，研究论文最多10页，且第10页只能包含参考文献。本次英文稿已按 sn-jnl 双栏模板排成9页。

重要说明：
“4天首次决定中位数”可能包含编辑初筛或退修，并不等于4天完成外审，更不能保证录用。审稿周期会因稿件质量、审稿人邀请和返修轮次而变化。传统订阅路线“通常无 APC”也不等于所有附加服务完全免费；彩色印刷、超长稿或其他特殊服务须以投稿时的最新说明为准。

六、学术伦理提醒

本次交付的中文稿和英文稿是同一研究的两种“备选投稿版本”。不得将实质内容高度相同的中英文稿同时投稿或分别发表，否则可能构成一稿多投或重复发表。请只选择一个版本投稿；若未来基于已发表版本扩展，必须新增实质性内容、引用原文并向编辑充分披露。投稿前还应确认所有作者同意作者顺序、贡献声明和最终文本。

七、最终结论

原稿：建议“大修后重审”。
本次修改后：文本、证据组织和版式已达到可送审水平；创新定位应坚持“尺度先验驱动的高分辨率预测”，不要再回到“多个注意力模块共同显著提升”的写法。能否达到北核或 SCI 最终录用标准，主要取决于多次重复、外部泛化、真实端侧测试以及投稿期刊的栏目匹配。
